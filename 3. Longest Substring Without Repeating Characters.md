
[3. Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

Given a string `s`, find the length of the **longest** **substring** without duplicate characters.

**Example 1:**

**Input:** s = "abcabcbb"
**Output:** 3
**Explanation:** The answer is "abc", with the length of 3. Note that `"bca"` and `"cab"` are also correct answers.

**Example 2:**

**Input:** s = "bbbbb"
**Output:** 1
**Explanation:** The answer is "b", with the length of 1.

**Example 3:**

**Input:** s = "pwwkew"
**Output:** 3
**Explanation:** The answer is "wke", with the length of 3.
Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.


## Burte force O(n^2)

O(n^2) as i in res is O(n)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        res = ""
        counter = 0

        for i in s:
            if i in res:
                res = res[res.index(i) + 1:]

            res += i
            counter = max(counter, len(res))

        return counter
```

You're trying to change the problem from **"find the longest substring with no repeating characters"** to **"count all substrings with no repeating characters."**

There are two important differences in your current code:

1. `if i in s:` is always true because `i` came from `s`.
    
2. `res` should represent the **current window**, not all of `s`.
    

### If you mean "count every substring with no repeated characters"

For example:

```text
s = "abc"
```

The valid substrings are:

```text
"a"
"b"
"c"
"ab"
"bc"
"abc"
```

So the answer is `6`.

A sliding-window version is:

```python
class Solution:
    def countUniqueSubstrings(self, s: str) -> int:
        left = 0
        count = 0
        seen = set()

        for right in range(len(s)):
            while s[right] in seen:
                seen.remove(s[left])
                left += 1

            seen.add(s[right])

            # Every substring ending at `right`
            # from left through right is valid.
            count += right - left + 1

        return count
```

### Why `count += right - left + 1`?

Suppose we're at:

```text
a b c
    ^
  right
```

The valid substrings ending at `c` are:

```text
"c"
"bc"
"abc"
```

That's **3**, which is:

```python
right - left + 1
3 - 0 + 1 = 3
```

Then for `"abc"`:

```text
right = 0 → +1   ("a")
right = 1 → +2   ("b", "ab")
right = 2 → +3   ("c", "bc", "abc")

total = 6
```

For `"aaa"`:

```text
"a"     ✓
"a"     ✓
"a"     ✓
```

There are 3 valid substrings, and the algorithm gives `3`.

---

If instead you mean **count literally every possible substring**, including ones with repeated characters, that's a different and much simpler calculation:

```python
n = len(s)
return n * (n + 1) // 2
```

For `"abc"` that's `6`; for `"aaa"` it's `6` (`"a"`, `"a"`, `"a"`, `"aa"`, `"aa"`, `"aaa"`).

So the key question is whether you want **all substrings** or **all substrings containing unique/non-repeating characters**.
