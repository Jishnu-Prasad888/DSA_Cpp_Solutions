[61. Rotate List](https://leetcode.com/problems/rotate-list/)

Given the `head` of a linked list, rotate the list to the right by `k` places.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/11/13/rotate1.jpg)

**Input:** head = [1,2,3,4,5], k = 2
**Output:** [4,5,1,2,3]

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/11/13/roate2.jpg)

**Input:** head = [0,1,2], k = 4
**Output:** [2,0,1]

**Constraints:**

- The number of nodes in the list is in the range `[0, 500]`.
- `-100 <= Node.val <= 100`
- `0 <= k <= 2 * 109`


### brute : time limit exceeded

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next || k == 0) return head;

        ListNode* h = head;

        int c = k;
        while (c > 0) {
            ListNode* curr = h;
            ListNode* prev = nullptr;

            // go to last node
            while (curr->next) {
                prev = curr;
                curr = curr->next;
            }

            // detach last node
            prev->next = nullptr;

            // move last node to front
            curr->next = h;
            h = curr;

            c--;
        }

        return h;
    }
};
```


## optimal 

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next || k == 0) return head;

        ListNode* t = head;
        int n = 1;

        // find length and last node
        while (t->next) {
            t = t->next;
            n++;
        }

        // make it circular
        t->next = head;

        k = k % n;
        if (k == 0) return head;

        int steps = n - k;
        ListNode* curr = head;
        ListNode* prev = nullptr;

        while (steps--) {
            prev = curr;
            curr = curr->next;
        }

        prev->next = nullptr;
        return curr;
    }
};
```

### What the error really means

```
heap-use-after-free in freeList
```

LeetCode is trying to **free your linked list**, but it detects a **cycle or corrupted structure**, so it ends up:

- visiting the same node again
    
- freeing it twice → **use-after-free**
    

---

### Root cause in your code

This line creates a cycle:

```cpp
t->next = head;
```

That’s fine _only if you break it correctly later._

But in your original code, because of the **wrong `n`**, this part:

```cpp
int c = n - k;
while(c--){
    prev = curr;
    curr = curr->next;
}
prev->next = nullptr;
```

**does NOT always break the cycle at the correct place.**

So the list sometimes remains **circular**, and when LeetCode tries to free it → crash.

---

### Why it specifically breaks

Because:

```cpp
n is wrong (length - 1)
k = k % n   // wrong modulus
c = n - k   // wrong split point
```

So you cut at the wrong node → **cycle not properly broken**

---

### Minimal failing scenario

Even a small case like:

```
[1,2], k = 2
```

Your code:

- computes wrong `n`
    
- computes wrong `k % n`
    
- never properly breaks the cycle
    

→ infinite loop during free → ASan error

---

### The fix (core idea)

You must guarantee **two things**:

1. `n` is correct
    
2. cycle is always broken exactly once

### Clean corrected logic

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next || k == 0) return head;

        ListNode* t = head;
        int n = 1;

        // सही length निकालो
        while (t->next) {
            t = t->next;
            n++;
        }

        // circular बनाओ
        t->next = head;

        k = k % n;
        if (k == 0) {
            t->next = nullptr;  // IMPORTANT: break cycle
            return head;
        }

        int steps = n - k;
        ListNode* curr = head;
        ListNode* prev = nullptr;

        while (steps--) {
            prev = curr;
            curr = curr->next;
        }

        prev->next = nullptr;  // break cycle
        return curr;
    }
};
```

### Key insight (this is what you missed)

Even when:

```cpp
k % n == 0
```

You still **already made the list circular**, so you _must_ break it:

```cpp
t->next = nullptr;
```

Otherwise → cycle → **heap-use-after-free**

- correct length?
    
- modulo done with correct `n`?
    
- cycle always broken?
    
- handled `k % n == 0`?
