Given a string `s` and a dictionary of strings `wordDict`, return `true` if `s` can be segmented into a space-separated sequence of one or more dictionary words.

**Note** that the same word in the dictionary may be reused multiple times in the segmentation.

**Example 1:**

**Input:** s = "leetcode", wordDict = ["leet","code"]
**Output:** true
**Explanation:** Return true because "leetcode" can be segmented as "leet code".

**Example 2:**

**Input:** s = "applepenapple", wordDict = ["apple","pen"]
**Output:** true
**Explanation:** Return true because "applepenapple" can be segmented as "apple pen apple".
Note that you are allowed to reuse a dictionary word.

**Example 3:**

**Input:** s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
**Output:** false

**Constraints:**

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` and `wordDict[i]` consist of only lowercase English letters.
- All the strings of `wordDict` are **unique**.

## Correct approach

This is a classic **Dynamic Programming** problem.

Let

```
dp[i]
```

mean:

> The first `i` characters of `s` can be segmented.

Transition:

```
dp[j] = true
if dp[i] == true
and s.substr(i, j-i) is in dictionary.
```

Time complexity:

- `O(n²)` (or `O(n² * L)` depending on substring/hash implementation)


## best solution : 

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        dp = [False] * (len(s)+1)

        dp[len(s)] = True
        i = 0
        for i in range(len(s)-1,-1,-1):
            for word in wordDict:
                if len(s) > (len(word) + i) and s[i:i+len(word)] == word:
                    dp[i] = True
                if dp[i]:
                    break

        return dp[0]
```

The key idea is **what `dp[i]` represents**.

For this problem:

```text
dp[i] = Can the substring s[i:] be segmented into dictionary words?
```

So `dp[i]` is **not** asking:

> "Does a word start at index `i`?"

It's asking:

> "Can the entire suffix starting at `i` be broken into valid words?"

### Computing `dp[4]`

Substring:

```text

```

Try `"code"`.

It matches.

Now ask:

> After taking `"code"`, can the **rest** be segmented?

The rest starts at

```text
4 + len("code") = 8
```

So we look at

```python
dp[8]
```

Since

```text
dp[8] = True
```

we know

```text
"code" + ""
```

is valid.

Therefore

```python
dp[4] = dp[8]
```

becomes

```text

```

Substring:

```text
s[0:] = "leetcode"
```

Try `"leet"`.

It matches.

Now ask:

> Is everything **after** `"leet"` breakable?

That means checking

```python
dp[4]
```

which we already computed.

Since

```text

```

we conclude

```text
"leet" + "code"
```

works.

So

```python
dp[0] = dp[4]
```

becomes

```text
dp[0] = True
```

## Why not just do `dp[i] = True`?

Suppose

```text
s = "catsandog"

wordDict = ["cat", "cats", "sand", "and", "dog"]
```

At index `0`:

```text
"cat"
```

matches.

If you write

```python
dp[0] = True
```

you're saying

> Since `"cat"` exists, the whole string is breakable.

But that's **not** true.

After `"cat"` comes

```text
"sandog"
```

which **cannot** be completely segmented.

The correct logic is

```python
dp[0] = dp[3]
```

because index `3` is where the remaining string starts.

If

```text
dp[3] = False
```

then

```text
"cat" + remaining
```

also fails.

---

### Think of it like recursion

The recursive solution is:

```cpp
if (word matches)
    return solve(nextIndex);
```

Notice it **doesn't** return `true` immediately after finding a matching word. It asks the recursive call whether the **remaining suffix** works.

The DP is the exact same logic:

```cpp
dp[i] = dp[nextIndex];
```

where

```text
nextIndex = i + len(word)
```

So:

- **Recursion:** `return solve(nextIndex);`
    
- **DP:** `dp[i] = dp[nextIndex];`
    

The DP array is simply storing the answers that the recursive calls would have returned. That's why `dp[i] = dp[i + len(word)]` is the correct transition rather than `dp[i] = True`.


## Standard DP solution

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> st(wordDict.begin(), wordDict.end());

        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;

        for (int i = 0; i < n; i++) {
            if (!dp[i]) continue;

            for (int j = i + 1; j <= n; j++) {
                if (st.count(s.substr(i, j - i))) {
                    dp[j] = true;
                }
            }
        }

        return dp[n];
    }
};
```


Here's a pure **recursion** solution first (without memoization). It works correctly, but it can cause a Time Limit Exceeded (TLE) on large test cases because it recomputes the same subproblems.

### Recursive Solution

```cpp
class Solution {
public:
    bool solve(int idx, string &s, unordered_set<string> &st) {
        // Reached the end of the string
        if (idx == s.size())
            return true;

        string word = "";

        for (int i = idx; i < s.size(); i++) {
            word += s[i];

            if (st.count(word)) {
                if (solve(i + 1, s, st))
                    return true;
            }
        }

        return false;
    }

    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> st(wordDict.begin(), wordDict.end());
        return solve(0, s, st);
    }
};
```

### How it works

Suppose:

```text
s = "leetcode"
dict = {"leet", "code"}
```

The recursion does:

```
solve(0)
│
├── "l"   ❌
├── "le"  ❌
├── "lee" ❌
└── "leet" ✅
      │
      └── solve(4)
            │
            ├── "c" ❌
            ├── "co" ❌
            ├── "cod" ❌
            └── "code" ✅
                    │
                    └── solve(8)
                            │
                            └── true
```

So the answer is `true`.

## Recursive + Memoization (Recommended)

This avoids recomputing the same index multiple times.

```cpp
class Solution {
public:
    bool solve(int idx, string &s, unordered_set<string> &st, vector<int> &dp) {
        if (idx == s.size())
            return true;

        if (dp[idx] != -1)
            return dp[idx];

        string word = "";

        for (int i = idx; i < s.size(); i++) {
            word += s[i];

            if (st.count(word) && solve(i + 1, s, st, dp))
                return dp[idx] = true;
        }

        return dp[idx] = false;
    }

    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> st(wordDict.begin(), wordDict.end());
        vector<int> dp(s.size(), -1);

        return solve(0, s, st, dp);
    }
};
```

- **Pure recursion:** Exponential time in the worst case (`O(2^n)`).
    
- **Recursion + memoization:** `O(n²)` time in the worst case (assuming average `O(1)` hash lookups) and `O(n)` extra space for the memoization array.
